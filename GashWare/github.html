Repository Architecture

A clean, modular Python codebase separated by core download engines, UI components, CLI monitors, and cross-platform packaging scripts.

📁 Python/core/
  • downloader.py: Multi-part parallel engine & work-stealing
  • manager.py: Download queue, state machine & locks
  • clipboard_monitor.py: Live URL background interception
  • settings.py: Thread pools, paths, and speed caps
📁 Python/gui/
  • gui_app.py: CustomTkinter main responsive dashboard
  • matrix_rain.py: Multi-threaded PIL matrix rain HUD
  • themes.py: 6 dynamic themes with instant redraw
  • components/: Download cards, speed meters, dialogs
📁 Python/cli/
  • cli_app.py: Standalone ncurses console interface
  • args.py: CLI flag parser (-t, -l, --resume, -o)
📁 Shell/ & Batch/
  • install_linux.sh: Automated Linux dependency & desktop setup
  • install_windows.bat: Windows virtualenv & icon installer
  • build_msi.bat: cx_Freeze 64-bit MSI compiler recipe

Building from Source

# 1. Create and activate a Python virtual environment
python -m venv .venv
source .venv/bin/activate # Or on Windows: .venv\Scripts\activate
# 2. Install dependencies
pip install -r Python/requirements.txt
# 3. Launch GUI or CLI
python Python/main.py
python Python/main.py --cli https://example.com/file.iso
